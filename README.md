A modern, highly interactive, and premium **Pure Vegetarian** food delivery platform inspired by Zomato. Built with **React (Vite), Tailwind CSS, Framer Motion, Context API, and LocalStorage**.

---

## ✨ Features

- **🛡️ 100% Veg Content**: Zero meat, seafood, or egg references. Fully eggless and vegetarian.
- **🟢 Veg Indicators**: Authentically styled Indian standard vegetarian badges next to every food item.
- **🔥 Trending Section**: Dedicated "Trending Veg Dishes" gallery with direct add-to-cart capability.
- **🛒 Persistent Cart**: State is stored via `localStorage` to keep items saved across refreshes.
- **🌗 Dark Mode**: Smooth theme toggle with modern glassmorphism UI.
- **🚀 Hash Routing**: Safe client-side routing on GitHub Pages via `HashRouter`.

---

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/shreyaraval/zomato-clone.git
cd zomato-clone

# Install dependencies
npm install

# Run dev server (accessible at http://localhost:5173/zomato-clone/)
npm run dev

# Build for production
npm run build
```

## 🌐 Deploy to GitHub Pages

1. In `package.json`, set your homepage:
   ```json
   "homepage": "https://shreyaraval.github.io/zomato-clone"
   ```
2. Deploy to GitHub Pages:
   ```bash
   npm run deploy
   ```
